# Shared spatial reference

`jldp_boundary.geojson` is the user-supplied Jack and Laura Dangermond Preserve boundary used for Level III/IV overlays and preserve-occurrence checks. It is a WGS84 polygon with 346 vertices. The original publication date and public download URL were not supplied.

The boundary checksum and source are recorded in [the source manifest](../../data/reference/source_manifest.json). The GBIF preserve snapshot retains its own boundary copy for provenance.

The CIBI identification extract used only by the earlier pipeline is retained in [the analysis archive](../archive/2026-10-30/analysis/reference-data/).
