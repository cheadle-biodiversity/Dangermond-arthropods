# Published Zenodo data archive

The dataset *Advancing Insect Conservation at Dangermond Preserve* is published at [Zenodo record 23819517](https://zenodo.org/records/23819517), DOI [10.5281/zenodo.23819517](https://doi.org/10.5281/zenodo.23819517).

It contains four final regional checklists, a checklist column descriptor, the Level III and IV occurrence tables, the original California GBIF archive and a README. See the [archive README](zenodo/README.md) and [file inventory](zenodo/deposit_file_inventory.csv).

This is a data-only archive. Code, analysis figures and supporting documentation remain in the [GitHub repository](https://github.com/cheadle-biodiversity/Dangermond-arthropods). The Ecdysis export and other supporting raw inputs are outside this deposit. Original record licenses and attribution remain applicable; the intended MIT code license does not apply to third-party data.

Published-record metadata were verified on 30 October 2026. Future updates should retain input versions, source citations and checksum manifests.
