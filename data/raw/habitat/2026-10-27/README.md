# Habitat reference downloads

Public CDFW ds2957 vegetation and USGS SIM 3472 polygon data, downloaded 27 October 2026. See archive_manifest.json for URLs, citations, sizes and SHA256 values.

CDFW field work dates span 2012–2017; the map predates dune restoration in 2022. USGS geology maps substrate, not present vegetation or species habitat preferences. Source files are unchanged; geometry repair and projection occur only in analysis.

Method: analysis/habitat-notes/README.md. Data annotation copies: data/final/habitat-notes/. Large source downloads are ignored by Git.
