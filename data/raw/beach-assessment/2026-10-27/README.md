# Dugan beach-ecosystem sources

Sources retrieved 27 October 2026 for the report's connection between Perko's
Beach insect records, wrack subsidies and beach ecosystem assessment.

DOI 10.25494/P6989J is a statewide 2019–2020 sandy-beach/surf-zone dataset,
published in 2022, not a Perko's-specific occurrence inventory. Its registered
second creator is spelled Marrifini; the companion report spells that author's
name Marraffini. Citations follow each source. These data have not been pooled
with the insect occurrence dataset or used to recalculate the Hill values.

The PDF companion report supports the food-web context and wrack–shorebird
association; the EML documents the measured environmental variables. Raw
files are ignored by Git. The source manifest retains URLs and checksums.
